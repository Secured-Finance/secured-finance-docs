# 🧙 Getting Started (UI v2)

This section walks you through using the [**USDFC app**](https://app.usdfc.net) — from opening your first Trove to redeeming USDFC. If you want the concepts first, start with the [Overview](../overview.md); the mechanics behind each operation live in [Core Mechanics](../core-mechanics/README.md).

| Guide | What it covers |
| --- | --- |
| [Creating Your First Trove](creating-your-first-trove.md) | Connect a wallet, deposit FIL, and mint your first USDFC |
| [Minting USDFC Step-by-Step](minting-usdfc-step-by-step.md) | Borrow more USDFC from an existing Trove |
| [Managing Collateral Effectively](managing-collateral-effectively.md) | Add or withdraw FIL and keep a healthy collateral ratio |
| [Monitoring Your Position](monitoring-your-position.md) | Track your Trove's health and react to price moves |
| [Using the Stability Pool](using-the-stability-pool.md) | Deposit USDFC and earn liquidation gains |
| [Redeeming USDFC](redeeming-usdfc.md) | Exchange USDFC for FIL at face value |
| [Getting Test USDFC on Testnet](getting-test-usdfc-on-testnet.md) | Try everything risk-free on the Calibration testnet |

## After minting

Once you hold USDFC, you can put it to work: deposit into the [Stability Pool](using-the-stability-pool.md), lend it in [Fixed-Rate Lending](../../fixed-rate-lending/overview.md), deposit into the [USDFC Vault](../../sf-yield-vault/core-mechanics/available-vaults-and-strategies/usdfc-lending-strategy.md), pair it with FIL on SushiSwap, or move it to other chains with the Bridge in the app.

Using the older interface at [legacy.usdfc.net](https://legacy.usdfc.net)? The flow is the same — see [Getting Started (UI v1)](getting-started/README.md) for matching screenshots.
{% endhint %}

# Monitoring System

On-chain event detection and alerts for Fixed-Rate Lending.

## Monitoring and alerts

Monitoring detects configured protocol events and sends alerts for review. It complements contract-level safeguards; it does not replace them.

## Filecoin deployment

The Filecoin monitoring update was deployed to production and checked on **13 October 2026 (UTC)**:

* **Alert delivery:** Tested by replaying recorded events.
* **Live processing:** Confirmed through sampled production checks.

These checks cover the observed intervals, not uninterrupted coverage. Monitoring cannot guarantee detection or prevention of every incident.

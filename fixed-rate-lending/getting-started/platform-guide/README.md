# Platform Guide

The [Secured Finance app](https://app.secured.finance/) has five main tabs:

| Tab | What it's for |
| --- | --- |
| [**Trading**](trading.md) | Place lend/borrow orders on the ZC bond order book |
| [**Markets**](markets.md) | Yield curves, market stats, and chain status — no wallet needed |
| [**Portfolio**](portfolio.md) | Deposits, withdrawals, collateral, positions, and history |
| [**Bridge**](bridge.md) | Move assets between supported networks (powered by Axelar) |
| [**Points & Campaigns**](points-and-campaigns.md) | Earn Secured Finance Points (SFP) for platform activity |

{% hint style="info" %}
Want to trade right away? Follow the [Quick Start: Lend](../quick-start-lend.md) or [Quick Start: Borrow](../quick-start-borrow.md) tutorials instead — they walk through only the steps you need.
{% endhint %}

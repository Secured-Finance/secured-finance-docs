## Before you start

You'll need:

1. **A Web3 wallet** (MetaMask, WalletConnect-compatible wallets, etc.) — see the [Wallet Setup guide](../../introduction/defi-starter-guide/wallet-setup.md) if you're new to this
2. **Assets to lend, or collateral to borrow against** — see [supported assets by network](../core-concepts/collateral.md)
3. **Native tokens for gas** on the required network (ETH on Ethereum/Arbitrum, FIL on Filecoin). An ordinary in-app [Swap](platform-guide/bridge.md) also needs source-network gas; if your wallet has no gas, arrange an incoming transfer first. See [Wallet Setup](../../introduction/defi-starter-guide/wallet-setup.md).

{% hint style="info" %}
**One concept to understand first:** lending means buying a Zero-Coupon bond, and borrowing means selling one. The execution price sets the rate for the current term. Maturity triggers Auto-Roll, not an automatic payment or repayment. Read [Zero-Coupon Bonds](../core-concepts/zero-coupon-bonds.md) for the PV/FV example, and each quick start’s funding, risk and exit checks before committing.
{% endhint %}
